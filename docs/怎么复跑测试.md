# 怎么复跑测试

仓库里已经留了六套测试的原始输出，只看出数的话不需要跑任何东西：

```bash
python eval_report.py
```

这条命令读 `测试留档/` 下的 log 与 `运营自检/golden_truth.json`，三十秒内重写 `评测报告.md`。

## 复跑六套测试的条件

六套测试原本跑在本地完整工程里，页面、测试脚本、规则库在同一层目录。公开仓库做了两处裁剪：只保留一份不含凭据的公开版页面，测试脚本收进 `tests/` 作为证据。所以要原样复跑，需要三样东西：

1. 把页面放回 `人机协作流程工具/运营场景人机协作流程工具.html`，测试脚本放到与页面同目录。
2. 自备访问凭据。`test_live.js` 会真调接口，公开版页面没有凭据，界面也会提示没有可用的凭据。
3. 本机装 Python 3.13 与 Node 22，另有 Chrome 或 Edge 供 `test_layout.py` 量文字包围盒。

顺序与命令，在 `人机协作流程工具/` 目录下执行：

```bash
node smoke_test.js
node test_edge.js
python test_layout.py
node test_live.js
python verify_flows.py
python ../运营自检/eval.py
```

两份负向测试在 `工程文件留底/` 下：

```bash
python 工程文件留底/负向测试-v332.py
python 工程文件留底/负向测试-泳道图布局.py
```

它们会临时破坏页面再自动还原，跑完请核对页面 md5 是否回到
`f630f63f70b6a99c98723bf0262c4730`。

## 本机环境踩过的坑

- Node 在本机不能派生任何子进程，调外部程序一律用 Python 的 subprocess。泳道图布局检查因此拆成 `render_flows.js` 只渲染、`test_layout.py` 调浏览器并判定。
- 无头浏览器要带 `--user-data-dir`，否则会去连已有实例、什么都不输出。
- 不要给 `global.URL` 赋普通对象，Node 的文件代理内部要做 `instanceof URL` 判断，覆盖后 `readFileSync` 会挂。只补 `createObjectURL`。
- 阈值判定写成 `!(值 >= 阈值)`，不要写 `值 < 阈值`，前者会让 NaN 当场暴露。
- 负向测试动手前先备份，启动时若发现上次留下的备份先自愈还原，循环体包 try/finally。

## 一条命令跑完并留档

本地完整工程里有两个封装脚本，会把每套输出原样写成 log：

```bash
python 跑六套测试.py
python 跑负向测试.py
python 步骤1验收.py
```

`步骤1验收.py` 会核对原页面 size 与 md5、公开版是否清空凭据、六套与两份负向测试的结果。
